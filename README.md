# Электронный Дневник (schools.by)

- **Production**: [urokby.vercel.app](https://urokby.vercel.app)
- **Repository**: [github.com/nadaroot/dnevnik](https://github.com/nadaroot/dnevnik)

Клиентский веб-интерфейс для работы с сервисом `e-schools.by` (`schools.by`). Строгий монохромный OLED-дизайн, аналитика успеваемости, калькулятор целей и трекер расписания в реальном времени.

---

### Функциональность

- [x] **Аналитика успеваемости**
  - Расчет текущего и предполагаемого среднего балла (GPA) по целевым оценкам
  - Цветовая дифференциация отметок: 1–4 (красный), 5–7 (желтый), 8–10 (белый)
  - График динамики баллов и выявление предметов в зоне риска
  - Счетчик дней до конца четверти и отслеживание каникулярных периодов

- [x] **Расписание и уроки**
  - Трекер учебного дня в реальном времени (идёт урок, перемена, до уроков, каникулы, выходной)
  - Таймер времени до звонка и информация о следующем уроке и кабинете
  - Недельное расписание уроков с подсветкой текущего урока

- [x] **Цели и планирование**
  - Калькулятор отметок (10, 9, 8) для достижения целевой четвертной оценки
  - Симулятор оценок с моделированием среднего балла

- [x] **Профиль и система**
  - Поддержка нескольких аккаунтов на одном устройстве
  - Проксирование запросов к шлюзу schools.by
  - Адаптация под мобильные устройства (PWA, safe-area-inset)

---

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Режим разработки
npm run dev
```

Локальный адрес: `http://localhost:3000`

---

### Сборка

```bash
# Production сборка
npm run build

# Запуск
npm start
```
